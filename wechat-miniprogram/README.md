# 青小寻 · 微信小程序源码

打开即显示离线矢量地图，单指拖动、双指缩放。地图包括新纺织大楼、17处校门/出入口、4个地下通道入口和54条店铺记录；浏园超市、一支味、再来吧水果店按新图从左到右独立标注。除铁门外的16个大门、4个地下通道入口和麦岛站B口可在地点目录寻址。出入口名称紧邻图标，不用长引线；南侧道路标为香港东路。点击“选楼寻路”后点两栋楼，计算步行参考路线；第三次点楼重新选择，清除按钮取消路线。西院4号门、东院3号门、北院2号门及三门之间道路已接入路网。86栋楼可选，78栋已接入当前路网，资料缺失处不会用直线替代路线。

「吃在青大」分为餐厅 8 条、商铺 / 校外 45 条、地下通道 1 条（青大路地下通道，含 12 家商户，按西院→东院顺序）。原“青大美食街”地图标记、目录及详情入口已删除。分类用顶部按钮切换；每个餐厅档口、商铺条目和地下通道商户都可点开，进入 1—5 星评分与评论页。

「学在青大」可选择本科生或研究生课表，打开对应青岛大学教务网站；课程可通过 UTF-8/GBK/UTF-16 编码的 CSV 或 .ics 日历文件导入，也可粘贴 CSV/日历内容或手动补录；按学期起始周一查看每周节次、时间、地点和教师。课表只保存在本机，不读取教务密码或登录网页。地图按当天课程、教学周和星期，在已有可靠位置的教学楼上显示荧光点；午夜及从后台返回时刷新。尚未实现从需登录的教务网页一键抓取课表。教务网站如要在小程序 web-view 内打开，需学校配合配置该域名为小程序业务域名；否则可复制网址到浏览器使用。

新纺织大楼使用教学建筑浅米色；润园和沁园只显示家属楼区域，删除单栋名字编号。地图指定标题、坐标说明、版权角标及估计位置文字后缀已移除，精度和许可放在“说明”中。沪上阿姨、古茗与浩园蜜雪冰城均已按用户截图加入地图；浩园12—14号楼名称和餐厅轮廓已校正。

## 本地导入与验证

1. 先在文件管理器中完整解压源码包。不要在微信开发者工具里双击或打开ZIP文件，否则它只会被当成二进制文件，模拟器会提示找不到`app.json`。
2. 打开微信开发者工具，选择“导入项目”，目录选解压后的根目录；该目录必须直接包含`app.json`和`project.config.json`，不能选择ZIP文件本身或它的上一级目录。
3. 项目已配置AppID `wx9590889b770efc12`。登录开发者工具的微信号必须是该小程序的管理员或开发者，才能预览、真机调试和上传。
4. 编译页面`pages/map/map`。选用稳定基础库版本，检查双指缩放、地点目录、评论入口、课表导入及今日楼宇点亮。
5. 本次不部署云函数、不上传开发版、不提交审核或发布。现有评论云端服务配置仍保持原状。

离线地图无需业务服务器、API Key、定位接口或第三方地图服务。用户明确同意隐私指引后才初始化云开发并使用联网业务，`traceUser`关闭；云端暂不可用时，评论只保存在本机且不会自动补发。本机存储失败会提示提交失败。不要在聊天里发送AppSecret、登录密码或签名密钥。

## 1.3.4 隐私保护更新

“说明”与评分评论页均提供隐私保护入口（`pages/privacy/privacy`），说明处理信息、用途、服务提供方、保存方式及联系方式。评论提交/查看云端评论前通过微信隐私按钮确认同意，拒绝后仍能浏览离线地图和资料。用户可删除本人云端评论、本机评论、清除本机评论或撤回同意。撤回不会自动删除云端评论；可先使用删除入口或联系开发者。公开评论列表不返回OpenID。

必须同步部署更新的`reviews`云函数，并将数据库设为仅云函数可访问。新增`authorOpenId`与`createdAt`组合索引用于查阅本人评论。旧版本云函数不支持本人删除功能，上传小程序代码不会自动更新云函数。

微信后台“设置 → 服务内容声明 → 用户隐私保护指引”仍需填写并提交，详见源码根目录`隐私指引后台填写说明.md`；仅添加代码或上传开发版不能完成该声明。

## 中国境内联网与评论

- 小程序版不申请或调用定位接口；步行参考路线通过手动选择起点和终点生成。
- 云开发由微信网络承载，不需要给云函数配置外部`request`合法域名。云环境必须绑定你自己的小程序AppID，游客AppID无法部署。
- 云函数部署与数据库初始化步骤见`cloudfunctions/README.md`。如工具没有自动选择环境，把环境ID写入`config.js`。

官方文档：https://developers.weixin.qq.com/miniprogram/dev/framework/
