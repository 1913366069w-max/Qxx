# 微信云开发部署

云开发用于中国境内的小程序内容同步与评论，不依赖境外网络链路。

1. 在微信开发者工具中换成自己的小程序AppID并开通云开发。
2. 新建数据库集合`content`和`reviews`；客户端不要开放直接写数据库权限。
3. 右键`content`和`reviews`两个云函数目录，分别选择“上传并部署：云端安装依赖”。
4. 在`content`集合建立文档ID`main`，字段`life`存放与小程序`data/campus.js`中`life`相同结构的数据。
5. 如开发者工具没有自动选中云环境，把环境ID填入项目根目录`config.js`的`cloudEnv`。

评论只通过云函数读写；返回列表不包含用户OpenID。1.3.4起新增本人评论查询、按OpenID核验删除、隐私版本校验；必须部署本次`reviews/index.js`，只上传小程序前端不会自动部署云函数。云端不可用时只保存本机评论，已移除外部HTTPS备用接口。

6. 给`reviews`集合创建组合索引：`authorOpenId`升序、`createdAt`降序（本人评论查询）；地点列表需要`targetId`升序、`createdAt`降序索引。
7. `content`与`reviews`集合客户端读写安全规则设置为`{"read":false,"write":false}`，由云函数服务端访问。不要给客户端开放集合读权限，否则可绕过公开列表读取身份字段。
8. 数据保存与隐私声明按源码根目录`隐私指引后台填写说明.md`配置。删除云端评论会同时删除该条记录内的OpenID；本机“撤回同意”只阻止后续业务请求，不会删除既有云端记录。停运时由运营者清理集合内的个人信息。
